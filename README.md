# Coding for Beginners - Tutorial Website

Welkom bij **Coding for Beginners** – een educatieve website die beginnende programmeurs helpt om HTML, CSS en JavaScript te begrijpen aan de hand van duidelijke uitleg, interactieve elementen en een quiz om je kennis te testen.

## 🌐 Inhoud van het project

De website bestaat uit vier hoofdonderdelen:

1. **HTML-pagina** – Uitleg over HTML-elementen zoals tags, attributen, lijsten, afbeeldingen, formulieren en meer.
2. **CSS-pagina** – (optioneel nog toe te voegen als volledige HTML-pagina) Uitleg over opmaak, selectors, kleuren, marges, etc.
3. **JavaScript-pagina** – Uitleg over variabelen, functies, arrays, DOM-manipulatie, events en meer.
4. **Quiz-pagina** – Een interactieve quiz met 10 meerkeuzevragen die de kennis uit de tutorial test.
5. **Tutorial-pagina** – Een externe pagina die uitlegt hoe dit project is opgebouwd.


## 💡 Hoe is het gemaakt?

### 🧱 HTML

Elke pagina bevat:
- Een `<header>` met navigatiebalk (`<nav>`)
- Een `<main>` gedeelte met een `section` die `cards` bevat
- Popover-elementen om korte uitleg te tonen bij elke kaart
- Buttons met `popovertarget` die de uitleg openen

### 🎨 CSS

Alle styling zit in `main.css`. De styling zorgt voor:
- Flexibele layout van kaarten
- Kleuren en typografie
- Styling van buttons en popovers
